# Команды и права

## `/doc` — документы

| Команда | Что делает | Право |
|---|---|---|
| `/doc` | Свои документы и сроки действия | `ostrak.use` (по умолчанию есть у всех) |
| `/doc show <игрок>` | Добровольно предъявить свой документ игроку рядом | `ostrak.use` |
| `/doc inspect <игрок>` | Потребовать документы у игрока рядом | `ostrak.inspect` (по умолчанию — оператор) |
| `/doc issue <тип> <игрок>` | Выдать документ | `ostrak.doc.<тип>` (например `ostrak.doc.passport`) |
| `/doc revoke <id>` | Изъять документ по id | `ostrak.revoke` (по умолчанию — оператор) |
| `/doc set <тип> <игрок> <поле> <значение>` | Изменить поле документа | `ostrak.doc.<тип>` |
| `/doc info <игрок>` | Все документы игрока | `ostrak.admin` |

`ostrak.doc.<тип>` — динамическое право на конкретный тип документа, отдельно
для каждого `id` типа (`ostrak.doc.passport` и т.д.). Не прописано в
`plugin.yml` заранее (типов может быть сколько угодно), поэтому системами
прав вроде LuckPerms выдаётся вручную. Пока право никому явно не выдано, им
обладают только операторы — так безопаснее по умолчанию, чем открыть всем.

## `/passport` (алиас `/pass`) — свой паспорт

| Команда | Что делает | Право |
|---|---|---|
| `/passport` | Открыть свой паспорт (или GUI, или сообщение "паспорта ещё нет") | `ostrak.use` |
| `/passport fill` | Продолжить анкету заполнения (только в `bootstrap-mode: self`) | `ostrak.use` |

## `/registry search` — поиск по реестру

| Команда | Что делает | Право |
|---|---|---|
| `/registry search <поле> <запрос>` | Поиск документов по значению searchable-поля | `ostrak.registry` (по умолчанию — оператор) |

Искать можно только по полям с `searchable: true` в описании типа — у
встроенного паспорта это `given_name`, `family_name`, `citizenship`.

## `/ostrak` — администрирование

| Команда | Что делает | Право |
|---|---|---|
| `/ostrak reload` | Перечитать `config.yml` и языковой файл | `ostrak.admin` |
| `/ostrak diagnostics` | Версия, тип хранилища, список типов документов, статус PlaceholderAPI | `ostrak.admin` |
| `/ostrak help` | Список всех команд плагина | `ostrak.admin` |
| `/ostrak update` | Проверить обновления на Modrinth | `ostrak.admin` |

Алиаса `/cp` не существует — только `/ostrak`.

## Полный список прав

| Право | По умолчанию | За что отвечает |
|---|---|---|
| `ostrak.use` | все игроки | базовые команды — `/doc`, `/doc show`, `/passport` |
| `ostrak.admin` | оператор | `/ostrak`, `/doc info` |
| `ostrak.revoke` | оператор | `/doc revoke` |
| `ostrak.inspect` | оператор | `/doc inspect` |
| `ostrak.inspect.force` | оператор | `/doc inspect` игнорирует согласие цели (расстояние по-прежнему проверяется) |
| `ostrak.registry` | оператор | `/registry search` |
| `ostrak.doc.<тип>` | оператор (по умолчанию не выдано) | `/doc issue`/`/doc set` для конкретного типа документа |

Все права, кроме `ostrak.use`, рассчитаны на выдачу через систему прав
(LuckPerms и подобные) отдельным ролям — не обязательно полноценным
администраторам. Например, `ostrak.doc.passport` можно выдать роли
"работник ЗАГСа", не трогая `ostrak.admin`.
