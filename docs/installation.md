# Установка

## Требования

| | |
|---|---|
| Сервер | Paper 1.20.1 – 1.21.x (форки Paper тоже подходят, ваниль/Spigot — нет) |
| Java | 17 (компиляция намеренно не в 21 — иначе отрезало бы 1.20.1) |
| Зависимости | нет обязательных. `PlaceholderAPI` — опционально, если он стоит, появляются плейсхолдеры `%ostrak_...%` |
| База данных | SQLite, встроена — отдельно ставить ничего не нужно |

## Шаги

1. Скачайте `Ostrak-Free.jar` с [Modrinth](https://modrinth.com).
2. Положите в `plugins/`.
3. Перезапустите сервер (не `/reload` — первый запуск должен создать структуру
   папок и файл базы).
4. Проверьте `plugins/OstrakFree/`:
   - `config.yml` — конфигурация (см. [Настройка](configuration));
   - `lang/ru_RU.yml` — все тексты сообщений (см. [Тексты и оформление](messages-and-styling));
   - `ostrak.db` — база SQLite, создаётся автоматически.
5. В консоли должно появиться:
   ```
   [OstrakFree] Ostrak включён: движок документов готов, встроенный тип «passport» загружен.
   ```
   Если вместо этого ошибка — см. [Частые вопросы](faq).

## Первая проверка

Зайдите на сервер и выполните `/passport` — если `citizen.bootstrap-mode` в
конфиге стоит на `self` (по умолчанию), тут же начнётся анкета заполнения
паспорта в чате. Дальше `/ostrak diagnostics` (нужно право `ostrak.admin`,
по умолчанию у оператора) покажет версию, тип хранилища и список
подключённых типов документов — если паспорт в списке, всё установлено верно.

## Обновление

Замените jar новой версией и перезапустите сервер. `config.yml` и
`lang/ru_RU.yml` при обновлении **не перезаписываются** — если в новой
версии появился новый ключ, придётся дописать его вручную (что за ключ и
зачем — смотрите в описании версии на Modrinth или в этой документации).
