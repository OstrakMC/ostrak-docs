# Паспорт и его поля

Паспорт — не особый случай в коде, а обычный тип документа, чьё описание
(`passport.yml`) поставляется внутри jar. В free-сборке этот файл нельзя
переопределить своим — вместо правки YAML используется конфиг
(`passport.disabled-fields`, см. [Настройка](configuration)).

## Разделы GUI

| Раздел | Поля |
|---|---|
| ◆ Личность | Имя, Фамилия, Пол, Дата рождения, Место рождения, Фото |
| ◆ Семья | Семейное положение, Супруг(а) |
| ◆ Гражданство | Гражданство |
| ◆ Работа | Профессия |
| ◆ Контакты | Discord, Телеграм |

## Все поля

| Ключ | Название | Тип | Особенность |
|---|---|---|---|
| `given_name` | Имя | текст | ищется через `/registry search`, нельзя отключить |
| `family_name` | Фамилия | текст | ищется через `/registry search` |
| `gender` | Пол | выбор («Мужской»/«Женский») | в анкете — кнопками, не текстом |
| `birth_date` | Дата рождения | дата | из неё вычисляется возраст (`%ostrak_age%`) |
| `birth_place` | Место рождения | текст | |
| `citizenship` | Гражданство | текст | ищется через `/registry search` |
| `profession` | Профессия | текст | |
| `marital_status` | Семейное положение | текст | |
| `spouse` | Супруг(а) | ссылка на другого гражданина | **опционально** — не у всех есть, анкета не будет напоминать о нём бесконечно |
| `photo` | Фото | голова игрока | автоматически, не спрашивается в анкете |
| `discord` | Discord | текст | |
| `telegram` | Телеграм | текст | |

## Отключение полей

Если какое-то поле не нужно вашему серверу (например, вы не используете
Discord-интеграцию), уберите его целиком через `config.yml`:

```yaml
passport:
  disabled-fields: [discord, telegram, profession]
```

Отключённое поле пропадает из GUI, из анкеты заполнения и из `/doc set`
(команда ответит «нет такого поля»). Уже сохранённые значения не удаляются —
просто скрываются, пока поле не включат обратно.

## Анкета заполнения (`bootstrap-mode: self`)

При первом входе (и по `/passport fill`, если анкета не закончена) плагин
спрашивает поля по одному. У каждого вопроса — кликабельная кнопка
«Пропустить» (не нужно печатать слово руками), а у полей с ограниченным
набором значений (например, «Пол») — кнопка на каждый вариант, чтобы не
ошибиться в написании.

«Пропустить» действует только на текущий заход в игру — при следующем входе
плагин снова спросит незаполненное поле, **кроме** опциональных
(`spouse`) — их пропуск не считается «анкета не дозаполнена», и подсказка
на входе про них не напоминает.
