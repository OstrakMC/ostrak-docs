# Частые вопросы

## Плагин не запускается / ошибка при старте

Проверьте версию Java (нужна ровно 17 — не 21, не 11) и версию Paper
(1.20.1–1.21.x). Ваниль/Spigot не поддерживаются — плагин использует
Adventure/Paper API, которых там нет.

## Игрок пишет в чат, а вместо сообщения плагин что-то спрашивает

Это анкета заполнения паспорта (`bootstrap-mode: self`) — она перехватывает
следующее сообщение как ответ на вопрос. Нажмите кнопку «Пропустить» под
вопросом (или напишите «пропустить» руками), чтобы выйти из анкеты, и
допройти её потом через `/passport fill`.

## Как убрать поле, которое не нужно (например Discord)

`config.yml` → `passport.disabled-fields: [discord]`. Подробнее —
[Паспорт и его поля](passport-and-fields).

## Как поменять текст/цвет сообщений

`plugins/OstrakFree/lang/ru_RU.yml` — правьте свободно, `/ostrak reload`
применяет изменения без рестарта. Подробнее —
[Тексты и оформление сообщений](messages-and-styling).

## `/doc issue passport <игрок>` — «нет прав», хотя я оператор

`ostrak.doc.<тип>` — динамическое право, не связанное с `ostrak.admin`.
Оператору оно доступно по умолчанию (как и все незарегистрированные права),
но если у вас стоит система прав вроде LuckPerms и она перекрывает
дефолтное поведение — выдайте право явно: `ostrak.doc.passport`.

## Игрок умер — паспорт пропал?

Зависит от `death.mode` в конфиге. По умолчанию (`auto`) — ничего не
происходит с паспортом, только переиздаётся физический предмет, если он
потерян. `restore` — паспорт аннулируется при смерти, восстановить может
только тот, у кого есть `ostrak.doc.passport`. Подробнее —
[Настройка](configuration).

## Хочу свой тип документа (права, лицензия, медкарта)

В free-сборке доступен только встроенный паспорт. Свои типы документов
(`documents/*.yml`) — функция premium-версии.

## Где хранятся данные

SQLite, файл `plugins/OstrakFree/ostrak.db`. В premium (веб-портал) —
PostgreSQL.

## Плагин конфликтует с другим плагином документов/паспортов

Отключите второй плагин или разведите команды через алиасы на уровне
сервера (например через плагин командных алиасов) — Ostrak не умеет
работать в паре с другой системой документов на одних и тех же полях.
